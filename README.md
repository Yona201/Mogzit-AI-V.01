# Mogzit AI (v0.1)

An intelligent household scheduling engine designed to optimize daily task management and protect dedicated study blocks for students.

## Problem Statement
In many households, unpredictable daily chores create friction that disrupts focused study hours—disproportionately impacting young students. Mogzit AI automates routine allocation around protected learning windows.

## Core Features (v0.1)
- **Constraint-Based Scheduling:** Automatically plans chores around non-negotiable study hours.
- **Fair Allocation:** Balances task durations across household members.
- **Supabase Integration:** Managed database layer for users, task queues, and schedule outputs.

## Tech Stack
- **Language:** Python 3.x
- **Database:** Supabase (PostgreSQL)
- **Framework:** Flask / Web UI (In Development)
